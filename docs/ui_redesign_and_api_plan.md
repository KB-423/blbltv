# Bili for TV 视觉重构与接口完善实施方案

> **核心定位**：基于 Apple TV 纯净毛玻璃（Liquid Glass）质感重构全站视觉，引入“开屏即开播、上下切流、自动隐退纯享”的全新沉浸式首页，并分阶段完善 P0/P1 核心接口资产，严格落实 DpadRegion 区域嵌套防串焦与首焦定向规范。

---

## 一、 核心需求与改造原则

1. **视觉语言升级（选项 B + 排布 2）**：
   - **悬浮折叠微光侧边导轨（选项 B）**：靠左悬浮的半透明毛玻璃细条，未落焦时轻量通透，获焦展开微光胶囊。
   - **纯净毛玻璃宽卡片网格（排布 2）**：卡片采用 14px 大圆角、纯白微光边框（`0x2EFFFFFF`）与深邃黑色漫反射，拒绝粗重饱和色边框。
   - **彻底净化界面文案**：严禁在 UI 界面中直接堆砌任何开发者内部描述词、功能说明或人工宣传标签（如“高热聚合”、“首选项”等人工修饰语），还原纯粹、干净、高级的原生视觉。
2. **全新沉浸式纯享首页（即刻开播）**：
   - **进门即播**：应用启动或切回首页时，直接在全屏背景底层无缝起播推荐流首个视频；
   - **侧边悬浮滑轨**：在左侧导轨右侧，呈现一条精致半透明的竖向/横向推荐卡片流；
   - **上下无缝切流**：遥控器上下按键直接切换当前播放的视频源与信息；
   - **自动纯享隐藏**：超时无操作（如 5 秒）或切换视频后用户按确定键（OK），侧边栏与浮层平滑渐隐，进入全屏“纯享播放”；按任意遥控器按键时瞬间自愈唤醒。
3. **架构与焦点规范严密对齐**：
   - 全面遵守刚录入 `AGENTS.md` 的规范：结构区域包裹独立 `DpadRegion`，上下不同结构严禁左右串焦；
   - 水平最左首焦、垂直最上首焦，纯享播放以全屏视频画面本身为第一初始焦点。
4. **性能避坑底线**：
   - 避免在大量滚动卡片上滥用 GPU 杀手 `BackdropFilter`，全屏单例模糊背景 + 卡片高透叠加与微光白边，确保低端电视盒子稳定 60fps 满帧运行。

## 三、 详细设计与重构细节

### 1. 全新沉浸纯享首页 (`features/home/presentation/screens/tv_immersive_home_screen.dart`)
* **底层全屏播放器**：
  - 进入首页时，读取推荐视频列表的第一项，直接在最底层无边框满幅起播；
  - 伴随开播平滑淡入，音量与画质平缓就绪；
* **侧边悬浮推荐滑道 (Float Recommend Strip)**：
  - 位于左侧导轨右侧，采用半透明微光玻璃容器；
  - 展示当前视频的精炼标题、UP 主、播放进度，以及后续推荐的下一个视频微卡片；
  - **上下切流操作**：遥控器按向下键，直接将底层播放器无缝切换到下一条视频，卡片高亮联动；
* **纯享隐退与按键自愈唤醒**：
  - 用户选定视频后按 **OK 键**，或保持静止 **5 秒无操作**，导轨与卡片滑道以平滑淡出动画隐退；
  - 焦点自愈抓回全屏视频画面，大屏进入 100% 沉浸影院视效；
  - 用户按下遥控器任意方向键、确认键或返回键时，立刻唤醒侧边滑道与状态，焦点严密归位。

### 2. 悬浮折叠微光侧边导轨升级 (`features/main/presentation/widgets/tv_nav_rail.dart`)
* **外观形态**：
  - 宽度收窄为纯净悬浮细条，背景使用 `Color(0x18FFFFFF)` 配合 `0.8px` 极细微高光白边；
  - 移除所有带有生硬色彩的背景框；
* **交互细节**：
  - 未落焦时，图标呈现低饱和半透白色（`0x7AFFFFFF`）；
  - 获焦时，图标翻转为 100% 纯白，下方/后方浮起圆润白色胶囊，投射柔和漫反射白光；
  - 用户自导轨向右按键，顺畅流转进入沉浸首页的推荐滑道或卡片网格。

### 3. 毛玻璃宽卡片与通用布局 (`features/home/presentation/widgets/tv_video_card.dart` 等)
* **大圆角与微光纯白边**：
  - 卡片圆角统一为 `14px`；
  - 边框使用极轻微漫反射纯白边缘（`Color(0x24FFFFFF)`），落焦时提升至 `2.0px` 纯白微光（`Colors.white`）+ `scale: 1.05`；
* **信息排版净化**：
  - 彻底移除“精彩推荐”、“全网检索”、“首选项”等人工修饰标签；
  - 仅保留视频标题、UP 主、播放量与时长标签，字体采用优雅无衬线现代排版。

## 四、 接口完善计划 (P0 & P1 分步落地)

结合持久化归档的接口清单，分三个里程碑将核心功能接入真实 API：

| 阶段 | 目标模块 | 涉及接口 | 交付内容 |
| :--- | :--- | :--- | :--- |
| **阶段 1** | **沉浸纯享首页与基础体验** | `recommendFeedWeb` (`/x/web-interface/index/top/feed/rcmd`) | 1. 沉浸纯享首页上线（开屏起播、上下切流、纯享隐退）<br/>2. 悬浮微光侧边栏与卡片网格质感重做<br/>3. 彻底清除界面冗余标签 |
| **阶段 2** | **全屏播放器深度互动 (P0)** | 1. `/x/player/pagelist` (分P选集)<br/>2. `/x/player/online/total` (在线人数)<br/>3. `/x/v2/view/like/triple` (一键三连)<br/>4. `/x/web-interface/archive/has/like` 等 (互动状态) | 1. 播放器支持呼出多 P 选集抽屉，遥控器左右切集<br/>2. 控制栏展示实时在线人数<br/>3. 长按遥控器 OK 键触发一键三连动画与真实状态上报 |
| **阶段 3** | **激活左侧导轨专区 (P1)** | 1. `/x/web-interface/popular` (热门流)<br/>2. `/xlive/web-interface/v1/index/getList` (直播大厅)<br/>3. `/pgc/season/index/result` (番剧索引) | 1. 热门专区上线（综合热门与排行榜）<br/>2. 直播专区上线（直播间大屏无缝直连）<br/>3. 追番专区上线（新番时刻表与 PGC 专用流） |
